# Repos that need a Python venv when working inside a Docker sandbox.
# One repo directory name per line (relative to the wrapper root), e.g.:
#   repoA
#   repoB --extra dev
# .state/tools/sandbox_venvs.py builds each with `uv sync --frozen` at ~/venvs/<project>/<repo>,
# outside the mounted directory, passing anything after the name to `uv sync`. Use that for
# test dependencies kept in an extra (dependency groups such as `dev` are installed already).
# Ignored when not running in a sandbox.
